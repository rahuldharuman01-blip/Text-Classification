Text Classification Using Machine Learning

This project builds a system that reads a piece of text and assigns it to one of several predefined categories. A trained model handles the prediction, and a Flask API connects it to this web interface.

Objective

Automate text categorization so that reviews, messages, or articles can be sorted quickly and consistently, with a confidence score showing how sure the model is.
